# Book covers

Place portrait cover art at:

```text
public/books/<book-id>/cover.jpg
```

Current files were sourced from [Open Library Covers](https://openlibrary.org/dev/docs/api/covers). Replace any file with your own scan or licensed artwork if you prefer a specific edition — keep the same filename and the shelf will pick it up via `coverImage` in `components/books/catalog.ts`.
